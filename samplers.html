Still have questions?

How do samplers work?

Each sampler is hand-selected by our staff. The cigars are chosen to complement each other — same format (Robusto or Toro), different makers or wrappers, so you can compare apples to apples.

Visit Us in Portland

Are these the same cigars I can buy individually?

Yes — every cigar in a sampler is also available as a single. Samplers are a way to try a few before committing to a box, or to explore a category you haven't tried before.

Can I customize a sampler?

Not yet through the website, but if you call or come in, we can build a custom set for you. People do this for gifts all the time.

What's the difference between the Starter Pack and the Step Up Sampler?

The Starter Pack is all mild, all smooth — ideal if you've never smoked before. The Step Up Sampler introduces one medium-bodied cigar so you can see if you're ready to explore more strength.

Do samplers ship the same as individual cigars?

Yes — same packaging, same shipping speeds. Samplers over $49 ship free, same as any order.

Not sure which one to pick?

Call or come in. Our staff will point you in the right direction in about two minutes flat.
